# Lost Saga Developer Tools

A professional suite for managing, editing, and analyzing game files, built with precision.

## Architecture
- **Framework**: Next.js 16 (App Router, Turbopack)
- **Styling**: Tailwind CSS v4, custom AMOLED dark theme.
- **Components**: Shadcn UI + Lucide React Icons.

## UI/UX Guidelines (Strict)
This project enforces a **"Sleek Modern Tech"** Admin Portal aesthetic:
- **AMOLED Dark**: Pure black backgrounds (`#000000`) with zinc-950 panels (`#09090b`).
- **No Glow**: No radial gradients or excessive blurs.
- **Accents**: Amber (`#f59e0b`) is the primary highlight color.
- **Typography**: Outfit (Sans-Serif).
- **Structure**: Robust Admin Shell (Sidebar + Top Navbar).

*Note to AI Agents: Refer to `.agents/AGENTS.md` before making any frontend design changes.*

## Available Modules
- **INI Editor**: Advanced configuration editor with fast reading/writing and syntax formatting.

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
